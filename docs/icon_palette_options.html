配色方案 P1–P5（先选色，再更新插件）

当前插件图标不会被改动。下面 5 套配色都遵守设计手册： 24×24、2px 边距、软体积、同色描边、右下轻阴影、不用字母缩写。 请选一套后复制结果发给我。

设计手册硬性要求（Rhino 9 仍适用）

尺寸24 × 24 px · PNG RGBA · 透明底
内容区中间 20 × 20，四周留 2 px 给阴影
阴影Blur ≈2px · 右下 1px · 黑约 25%
颜色每个图标（或同一族）1 个色系；避免高饱和霓虹
文字尽量不要写 RF / Pred 等缩写（靠剪影识别）
对比软体积 + 柔和抗锯齿，贴近 GH 原生工具栏
规范来源：仓库 docs/icon_style_proposals_gh.html + McNeel / David Rutten GH 图标工艺说明。 样本图标见下方（从本机 Grasshopper 抽出）。

总览板：每行 = 一套配色的色条 + 6 个示例图标（分类 / 回归 / 聚类 / 数据 / 帮助 / 智能）。

P1 · 推荐稳妥

Classic GH Plastic

灰蓝 / 暖灰 / 橄榄，最像原生 Params。任务主要靠图形区分。

  • 和 GH 工具栏最搭
  • 长期耐看，教学/发布都稳
  • 不靠高饱和也能认
P2

Soft Task Hue

低饱和黄 / 橙 / 绿 = 分类 / 回归 / 聚类；工具灰蓝。语义最清晰。

  • Ribbon 上任务一眼可分
  • 仍是软塑料 + 低饱和
  • 适合教学演示
P3

McNeel Type Colors

对齐 GH 类型色：黄=数据、橙=曲面感、绿=数学、蓝=曲线、灰=参数。

  • 和原生几何/数据类型语言一致
  • 比 P2 稍鲜一点，但仍克制
  • 适合「像官方扩展」的感觉
P4

Ink Wash Sage

近单色灰绿水墨。最隐身进工具栏；色弱友好。

  • 几乎不抢戏
  • 任务全靠剪影
  • 适合极简审美
P5

Slate + Accent Chip

统一冷灰底座，右上角小色标区分任务。家族感最强。

  • 一组电池「看起来是一套」
  • 色标小，不破坏 GH 气质
  • 组件很多时最好管理
