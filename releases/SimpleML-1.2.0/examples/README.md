# SimpleML 示例与上架演示

请先运行 **环境体检**（或 **新手向导**）确认 `PASS`。

| 文件 | 内容 |
|------|------|
| `01_classification_iris.md` | 分类完整链路 |
| `02_clustering_color.md` | 聚类 + 几何上色 |
| `03_regression.md` | 回归 |
| `quickstart_classification.py` | 不依赖 GH 的核心验证脚本 |

## 最短路径（推荐演示）

```
新手向导 → 按 Recipe 搜索组件连接
或
加载示例数据集 → 分割 → 智能训练 → 预测 → 评估
```

## 安装

- Windows: 仓库根目录 `install.bat`  
- macOS: `bash install.sh`  
- 详见 `FOOD4RHINO.md` / `README.md`
