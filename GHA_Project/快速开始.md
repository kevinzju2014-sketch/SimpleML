# SimpleML GHA 文件构建 - 快速开始

## 🚀 三步构建 GHA 文件

### 步骤1: 检查环境（可选但推荐）

双击运行：`检查构建环境.bat`

这会检查：
- ✅ Visual Studio / MSBuild
- ✅ Rhino 8 DLL 文件
- ✅ 项目文件完整性
- ✅ Python 代码存在

### 步骤2: 在 Visual Studio 中构建

1. **打开项目**
   - 双击 `SimpleML.csproj` 文件
   - 或在 Visual Studio 中：`文件` → `打开` → `项目/解决方案`

2. **选择 Release 配置**
   - 顶部工具栏 → 配置下拉菜单 → 选择 `Release`

3. **构建项目**
   - 菜单：`生成` → `生成 SimpleML`
   - 或快捷键：`F6`
   - 或右键项目 → `生成`

4. **查看结果**
   - 打开 `输出` 窗口：`视图` → `输出`
   - 应该显示：`========== 生成: 成功 1 个 ==========`
   - 检查 `bin\Release\` 文件夹
   - 应该看到：`SimpleML.dll` 和 `SimpleML.gha`

### 步骤3: 安装到 Grasshopper

1. **复制 GHA 文件**
   ```
   从: bin\Release\SimpleML.gha
   到: %APPDATA%\Grasshopper\Libraries\SimpleML.gha
   ```

2. **复制 Python 代码**
   ```
   从: D:\Helio\250928_机器学习课程\myML\
   到: %APPDATA%\Grasshopper\UserObjects\SimpleML\myML\
   ```

3. **重启 Grasshopper**
   - 关闭所有 Rhino/Grasshopper 窗口
   - 重新启动 Rhino
   - 打开 Grasshopper，检查组件是否出现

## ⚡ 快速命令

### 使用命令行构建（如果已安装 MSBuild）

```cmd
cd /d "D:\Helio\250928_机器学习课程\myML\GHA_Project"
build.bat
```

### 使用 dotnet CLI 构建

```cmd
cd /d "D:\Helio\250928_机器学习课程\myML\GHA_Project"
dotnet restore
dotnet build -c Release
copy bin\Release\SimpleML.dll bin\Release\SimpleML.gha
```
