# 分类模型评估指标说明

## 评估报告中的指标含义

当您使用 **Evaluate Classification** 组件评估分类模型时，Report 输出会显示类似以下的报告：

```
              precision    recall  f1-score   support

      类别0       0.95      0.93      0.94        50
      类别1       0.92      0.94      0.93        48
      类别2       0.96      0.98      0.97        52

    accuracy                           0.95       150
   macro avg       0.94      0.95      0.95       150
weighted avg       0.95      0.95      0.95       150
```

---

## 📊 各指标详细说明

### 1. **Precision（精确率/查准率）**

**定义**：在所有被模型预测为正例的样本中，实际为正例的比例。

**公式**：
```
Precision = TP / (TP + FP)
```
- TP (True Positive): 真正例 - 预测为正，实际也为正
- FP (False Positive): 假正例 - 预测为正，实际为负

**通俗理解**：
- **"模型说对的，有多少真的对了"**
- 例如：模型预测100个样本为"猫"，其中95个真的是"猫"，精确率就是95%

**数值范围**：0 到 1
- **1.0** = 完美（所有预测为正例的都是对的）
- **0.0** = 完全错误
- **> 0.7** = 通常认为较好

**使用场景**：
- 当**误报成本高**时，需要高精确率
- 例如：垃圾邮件检测（不希望把正常邮件误判为垃圾邮件）

---

### 2. **Recall（召回率/查全率）**

**定义**：在所有实际为正例的样本中，被模型正确预测为正例的比例。

**公式**：
```
Recall = TP / (TP + FN)
```
- TP (True Positive): 真正例
- FN (False Negative): 假负例 - 预测为负，实际为正

**通俗理解**：
- **"实际为正的，模型找到了多少"**
- 例如：实际有100个"猫"，模型找到了93个，召回率就是93%

**数值范围**：0 到 1
- **1.0** = 完美（找到了所有正例）
- **0.0** = 完全没找到
- **> 0.7** = 通常认为较好

**使用场景**：
- 当**漏报成本高**时，需要高召回率
- 例如：疾病诊断（不希望漏诊病人）

---

### 3. **F1-Score（F1分数）**

**定义**：精确率和召回率的调和平均数，综合评估模型性能。

**公式**：
```
F1-Score = 2 × (Precision × Recall) / (Precision + Recall)
```

**通俗理解**：
- **"精确率和召回率的平衡值"**
- 当精确率和召回率都很高时，F1分数也高
- 当其中一个很低时，F1分数会被拉低

**数值范围**：0 到 1
- **1.0** = 完美（精确率和召回率都是1.0）
- **0.0** = 最差
- **> 0.7** = 通常认为较好

**使用场景**：
- 需要**平衡精确率和召回率**时
- 当数据集类别不平衡时，F1分数比准确率更有参考价值

**为什么需要F1分数？**
- 只看精确率：可能召回率很低（找到了很少的正例）
- 只看召回率：可能精确率很低（预测了很多错误的正例）
- F1分数综合考虑两者，给出更全面的评估

---

### 4. **Support（支持数）**

**定义**：每个类别在测试集中实际出现的样本数量。

**通俗理解**：
- **"测试集中每个类别有多少个样本"**
- 例如：类别0有50个样本，类别1有48个样本

**用途**：
- 了解测试集的**类别分布**
- 判断数据集是否**类别不平衡**
- 评估指标的可信度（样本越多，指标越可靠）

**示例**：
- Support = 50：该类别的测试样本有50个
- Support = 5：该类别的测试样本只有5个（样本少，指标可能不够可靠）

---

## 📈 报告中的其他指标

### **Accuracy（准确率）**

**定义**：所有预测中，预测正确的比例。

**公式**：
```
Accuracy = (TP + TN) / (TP + TN + FP + FN)
```

**通俗理解**：
- **"所有预测中，对了多少"**
- 例如：预测150个样本，对了142个，准确率就是94.7%

**注意**：
- 当类别不平衡时，准确率可能**误导**
- 例如：99%的样本是类别A，模型全部预测为A，准确率99%，但模型实际上很差

---

### **Macro Avg（宏平均）**

**定义**：所有类别指标的简单平均值。

**计算方式**：
```
Macro Avg = (类别1指标 + 类别2指标 + ... + 类别N指标) / N
```

**特点**：
- **每个类别权重相同**
- 适合关注**每个类别的性能**，不受样本数量影响

**使用场景**：
- 类别重要性相同
- 类别样本数量差异很大时，更能反映模型对少数类的表现

---

### **Weighted Avg（加权平均）**

**定义**：根据每个类别的样本数量（support）加权平均。

**计算方式**：
```
Weighted Avg = Σ(类别指标 × 类别样本数) / 总样本数
```

**特点**：
- **样本多的类别权重更大**
- 更能反映模型在**整体数据集**上的表现

**使用场景**：
- 关注整体性能
- 样本多的类别更重要时

## 🎯 实际应用示例

### 示例1：二分类问题（垃圾邮件检测）

```
              precision    recall  f1-score   support

    垃圾邮件       0.95      0.90      0.92       100
    正常邮件       0.98      0.99      0.98       900

    accuracy                           0.98      1000
```

**解读**：
- **垃圾邮件精确率0.95**：预测为垃圾邮件的，95%真的是垃圾邮件（误报率5%）
- **垃圾邮件召回率0.90**：实际垃圾邮件中，找到了90%（漏报率10%）
- **正常邮件精确率0.98**：预测为正常邮件的，98%真的是正常邮件
- **正常邮件召回率0.99**：实际正常邮件中，找到了99%

**建议**：
- 如果更关心**不要误判正常邮件**（误报成本高），关注正常邮件的精确率
- 如果更关心**不要漏掉垃圾邮件**（漏报成本高），关注垃圾邮件的召回率

---

### 示例2：多分类问题（图像分类）

```
              precision    recall  f1-score   support

        猫       0.95      0.93      0.94        50
        狗       0.92      0.94      0.93        48
        鸟       0.96      0.98      0.97        52

    accuracy                           0.95       150
   macro avg       0.94      0.95      0.95       150
weighted avg       0.95      0.95      0.95       150
```

**解读**：
- 每个类别的性能都很接近，说明模型**平衡性好**
- 所有类别的F1分数都在0.93-0.97之间，**性能优秀**
- Macro avg和Weighted avg接近，说明**类别分布均衡**

## 📋 如何解读评估报告

### 1. **看整体性能**
- 查看 **accuracy**（准确率）
- 查看 **macro avg** 和 **weighted avg** 的 F1-score

### 2. **看各类别性能**
- 检查每个类别的 **precision**、**recall**、**f1-score**
- 找出**表现差的类别**（指标明显低于其他类别）

### 3. **看类别平衡**
- 比较各类别的 **support**（样本数量）
- 如果差异很大，关注 **macro avg** 而不是 **weighted avg**

### 4. **根据需求选择指标**
- **需要高精确率**：关注 precision（减少误报）
- **需要高召回率**：关注 recall（减少漏报）
- **需要平衡**：关注 f1-score

## ⚠️ 常见问题

### Q1: Precision 和 Recall 哪个更重要？

**答案**：取决于应用场景
- **精确率更重要**：误报成本高（如：医疗诊断、金融欺诈检测）
- **召回率更重要**：漏报成本高（如：疾病筛查、安全检测）
- **两者平衡**：使用 F1-score

### Q2: 为什么有些类别的指标是 0.00？

**可能原因**：
1. 测试集中**没有该类别的样本**（support = 0）
2. 模型**完全无法识别**该类别
3. 数据**类别不平衡**严重

**解决方法**：
- 检查数据集是否包含该类别
- 增加该类别的训练样本
- 使用类别权重平衡

### Q3: Macro Avg 和 Weighted Avg 差异很大怎么办？

**原因**：类别样本数量差异大（类别不平衡）

**建议**：
- 如果每个类别都重要：关注 **Macro Avg**
- 如果样本多的类别更重要：关注 **Weighted Avg**
- 考虑使用**类别权重**或**过采样/欠采样**

## 📚 总结

| 指标 | 含义 | 关注点 | 数值范围 |
|------|------|--------|----------|
| **Precision** | 预测为正例中，实际为正例的比例 | 减少误报 | 0-1，越高越好 |
| **Recall** | 实际为正例中，被正确预测的比例 | 减少漏报 | 0-1，越高越好 |
| **F1-Score** | 精确率和召回率的平衡值 | 综合性能 | 0-1，越高越好 |
| **Support** | 测试集中该类别的样本数量 | 样本分布 | 整数，越多越可靠 |
| **Accuracy** | 所有预测中，预测正确的比例 | 整体正确率 | 0-1，越高越好 |

**记住**：
- **Precision** = "说对的，有多少真的对了"
- **Recall** = "实际对的，找到了多少"
- **F1-Score** = "两者的平衡"
- **Support** = "有多少样本"
