## 📋 构建步骤

### 方法1: 使用 Visual Studio（推荐）⭐

#### 步骤1: 打开项目

1. 启动 **Visual Studio**
2. 选择 `文件` → `打开` → `项目/解决方案`
3. 导航到：
   ```
   D:\Helio\250928_机器学习课程\myML\GHA_Project
   ```
4. 选择 `SimpleML.csproj` 并打开

**或者**：直接在文件资源管理器中双击 `SimpleML.csproj` 文件

#### 步骤2: 检查项目加载

在 `解决方案资源管理器` 中确认：
- ✅ `SimpleML` 项目已加载
- ✅ `Components` 文件夹可见（包含所有 .cs 文件）
- ✅ `引用` 节点展开后没有黄色警告图标

**如果有警告**：
- 检查 Rhino 8 安装路径是否正确
- 编辑 `SimpleML.csproj` 中的 `<HintPath>` 路径

#### 步骤3: 选择 Release 配置

1. 在顶部工具栏找到 **配置下拉菜单**
2. 选择 `Release`（不是 Debug）
3. 平台选择 `AnyCPU`

#### 步骤4: 构建项目

**推荐方法**：
1. 点击顶部菜单：`生成` → `生成 SimpleML`
2. 或使用快捷键：`F6`
3. 或右键项目 → `生成`

**查看构建进度**：
- 打开 `输出` 窗口：`视图` → `输出`
- 选择"显示输出来源：生成"
- 观察构建过程

**构建成功标志**：
```
========== 生成: 成功 1 个，失败 0 个，最新 0 个，跳过 0 个 ==========
```

#### 步骤5: 验证 GHA 文件

构建成功后，检查：

1. **在解决方案资源管理器中**：
   - 展开 `bin` → `Release`
   - 应该看到：
     - `SimpleML.dll` ✅
     - `SimpleML.gha` ✅（自动创建）

2. **如果只有 DLL 文件**：
   - 手动复制 `SimpleML.dll` 并重命名为 `SimpleML.gha`

3. **验证文件**：
   - 文件大小不应为 0 字节
   - 两个文件大小应该相同

## 🔧 常见问题解决

### 问题1: 找不到 MSBuild

**错误信息**：
```
MSBuild not found!
```

**解决方案**：
- 安装 Visual Studio 2019/2022
- 或安装 Visual Studio Build Tools 2022
- 或安装 .NET SDK 6.0+

### 问题2: 找不到 Grasshopper.dll

**错误信息**：
```
无法解析引用 "Grasshopper"
```

**解决方案**：
1. 确认 Rhino 8 已安装
2. 检查路径：`C:\Program Files\Rhino 8\Plug-ins\Grasshopper\Grasshopper.dll`
3. 如果路径不同，编辑 `SimpleML.csproj` 中的 `<HintPath>`

### 问题3: 缺少 .NET Framework 4.8

**错误信息**：
```
找不到 .NET Framework 4.8
```

**解决方案**：
1. 下载安装：https://dotnet.microsoft.com/download/dotnet-framework/net48
2. 重启 Visual Studio
3. 重新加载项目

### 问题4: 编译错误

**查看错误**：
1. 打开 `错误列表` 窗口：`视图` → `错误列表`
2. 查看所有错误和警告
3. 双击错误查看详细信息

**常见错误**：
- 缺少引用：检查 `引用` 节点
- 语法错误：检查代码
- 命名空间错误：检查 using 语句

### 问题5: 构建成功但没有 GHA 文件

**解决方案**：
1. 手动复制 DLL 并重命名为 GHA：
   ```cmd
   copy bin\Release\SimpleML.dll bin\Release\SimpleML.gha
   ```
2. 或检查 `输出` 窗口是否有 PostBuild 相关错误

## 📦 安装 GHA 文件

构建成功后，安装 GHA 文件：

### 步骤1: 复制 GHA 文件

将 `bin\Release\SimpleML.gha` 复制到：
```
%APPDATA%\Grasshopper\Libraries\
```

**完整路径示例**：
```
C:\Users\Administrator\AppData\Roaming\Grasshopper\Libraries\SimpleML.gha
```

### 步骤2: 复制 Python 代码

将 `myML` 文件夹复制到：
```
%APPDATA%\Grasshopper\UserObjects\SimpleML\myML
```

**完整路径示例**：
```
C:\Users\Administrator\AppData\Roaming\Grasshopper\UserObjects\SimpleML\myML\
```

**需要复制的文件夹结构**：
```
myML\
├── components\
│   ├── __init__.py
│   ├── algorithms\
│   └── [所有 .py 文件]
├── core\
│   └── [所有 .py 文件]
└── requirements.txt
```

### 步骤3: 重启 Grasshopper

1. 关闭所有 Rhino 和 Grasshopper 窗口
2. 重新启动 Rhino
3. 打开 Grasshopper
4. 检查组件是否出现在组件面板中
